# RTO Interaction Probability

Simple question: If two employees are told to work from the office N-days per week, what is the likelihood they attend on the same days?

This is a very simple analysis to answer that question. It calculates the probability for between 2 and 10 workers coming to the office between 1 and 5 (inclusive) days per week.
